# S-02 - Global rate-limit bucket DoS

**Status:** DONE (with deployment note) (2026-10-26, branch arena/a703a62a-web-stor)

**Fix:** Cart/checkout limiting moved to PostgreSQL auth_rate_limits via enforceRateLimit() (multi-key: client + per-cart), in-memory only as DB-outage fallback. clientKey() uses trusted IP or a per-client header fingerprint - the single untrusted-proxy bucket is gone.

**Evidence:** Unit: client-ip tests; live: cart POST probes return 413/415/403 without DB. Multi-instance sharing is by construction (same table as auth limiter); requires DATABASE_URL in deployment.
