# S-13 - Admin gate single env email

**Status:** SUPERSEDED by S-25 (2026-11-25) — web admin eliminated, administration is local-only.

**Original fix (2026-10-26, branch arena/a703a62a-web-stor):** users.role honored + ADMIN_EMAIL bootstrap, verified email required, 404 for all non-admins incl signed-out, audit events. MFA and admin TTL were never added.

**Current state (S-25):** there is no web admin surface left to gate. `src/app/admin/page.tsx` is deleted and `/admin` + `/admin/**` return `404` with `private, no-store` to **everyone**, so "404 for non-admins" became "404 for every visitor". Administration moved to the local owner CLI (`scripts/owner-ops.ts`, `npm run ops`), which refuses to run inside a web request and is never imported by `src/app/**`. The `users.role` column and the `ADMIN_EMAIL` bootstrap remain in the schema for compatibility but no web route uses them for authorization. MFA for administration is therefore no longer applicable: the CLI requires shell access to a host that can reach the database.

**Evidence:** live probe `/admin` → `404` + `private, no-store, no-cache, must-revalidate`; `tests/threat-shield.test.ts` asserts the page file is gone and no source links to the admin surface; `tests/threat-shield-db.test.ts` drives the real proxy.
