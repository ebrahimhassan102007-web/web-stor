## 1. ملخّص التغييرات

### الهوية البصرية الجديدة
- **لوحة الألوان:** خلفيات زيتية داكنة جدًا (`#06060a → #15151e`) بمسحة دافئة، ووضع نهاري بلون العاج الدافئ (`#f5f1ea → #fffefb`) — **ليس انعكاسًا للوضع الليلي**.
- **الإضاءة:** ثلاث هالات فجر ثابتة (شمبانيا / وردة / بنفسجي) بحركة بطيئة جدًا (64–96 ثانية) داخل طبقة `DawnStage` واحدة، مع حبيبات خفيفة.
- **اللمسات الذهبية:** `--champagne #ecd9b4`؛ وفي الوضع النهاري يصبح `#9a7434` لتبقى نسبة التباين 4.9:1 على العاج.
- **الزجاج:** أسطح شبه شفافة مع حدّ شعري مضيء من الأعلى (masked 1px gradient)، بدل الحدود الثقيلة.
- **العمق:** ظلال دافئة متعددة الطبقات بدل الضوضاء اللونية.
- **الخطوط:** نمط عنوان واحد `title-luxe`، ونمط سطر تمهيدي واحد `eyebrow`.

### نظام الحركة (CSS + React فقط — بدون أي مكتبة حركة)
| الأداة | الوظيفة |
|---|---|
| `reveal` / `rise-in` | ظهور تدريجي عند التمرير/الدخول مع تأخير لكل عنصر |
| `dawn-glow-a/b/c` | الحركة المحيطة بالخلفية (transform فقط) |
| `hero-aurora` | شفق بطيء داخل الـ Hero |
| `float-soft` | طَفْو خفيف لشعار "E" الزجاجي فقط |
| `sheen` / `card-media-zoom` | لمعة عند المرور + تكبير صورة المنتج (النص لا يتحرك) |
| `btn-primary/ghost/icon` | رفع عند التمرير + انضغاط `active:scale(.985)` |
| `skeleton` | هياكل تحميل مطابقة للأبعاد النهائية (بدون قفزة) |

**الالتزامات:** الحركة على `opacity/transform` فقط ⇒ **لا CLS**؛ كل الحركات تتوقف تمامًا مع `prefers-reduced-motion`؛ لا يوجد أي `animation` لا نهائي غير الهالات البطيئة؛ ولا يوجد fallback عبر JavaScript يمنع الظهور لو تعطّل.

### الصفحات التي أُعيد تصميمها
الرئيسية (Hero سينمائي + شعار زجاجي + بحث فاخر + شرائح ثقة + أعمدة + إشعار + تصنيفات + منتجات مميزة) · الهيدر (زجاج يتفاعل مع التمرير + شعار متدرّج + أزرار أيقونية + **قائمة تنقّل سطح مكتب جديدة** + درج جانبي محسّن) · بطاقة المنتج · قائمة المنتجات والفلاتر · صفحة المنتج · السلة · الدفع + النجاح · تسجيل الدخول · لوحة الحساب/الطلبات/المحفظة/تنقّل الحساب · العروض · صفحات المعلومات (من نحن، الأسئلة، التواصل، السياسات) · بوت الدعم · لوحة الإدارة · الفوتر · صفحة 404 · حالات التحميل.

### تعدد اللغات والاتجاه
- خصائص منطقية فقط (`ms/me`، `start/end`، `inset-inline`) ⇒ كل شيء ينعكس صحيحًا في العربية: العلامة الزجاجية، الهالات، الزخارف، حركة الدرج، الأسهم.
- **خط Cairo سليم**: قاعدة `html[lang="ar"] * { letter-spacing: normal !important }` محفوظة، وكل `letter-spacing` الجديد محصور في `html[lang="en"]` فقط ⇒ لا كسر للحروف المتصلة.

### الوصولية (لم تُفقد أي وظيفة)
- كل `data-testid` محفوظ (`menu-toggle`، `nav-drawer`، `menu-overlay`، `header-add-funds`، `drawer-add-funds`)، و16 رابطًا في الدرج، وأهداف 44px (`h-11 w-11`)، ومصيدة التركيز، وإغلاق بـ Escape مع عودة التركيز.
- الطبقات الزخرفية `aria-hidden` و`pointer-events-none`؛ الهياكل تحمل `aria-busy` + نصًا لقارئ الشاشة.
- حلقة تركيز عامة `:focus-visible`؛ التباين: النص الثانوي 8.6:1 ليلي / 5.4:1 نهاري.
