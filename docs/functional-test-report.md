# تقرير الاختبار الوظيفي للموقع

**التاريخ:** 2026-10-24  
**النطاق:** إصلاح مشاكل عرض المنتجات والقائمة والتنقل؛ من دون إنشاء مشروع جديد أو تغيير الـstack أو الـAPI أو بنية قاعدة البيانات.

## بيئة الاختبار

- Next.js 16.4.2 وReact 19 على خادم التطوير الحالي.
- Chromium 153 مع Playwright، باستخدام محاكاة شاشة كمبيوتر **1440×900** وشاشة موبايل **390×844**. هذا اختبار متصفح بمحاكاة المقاس، وليس اختبارًا على جهاز مادي.
- لاختبار حالة قاعدة البيانات الفارغة، استُخدمت قاعدة **PGlite مؤقتة داخل الذاكرة** على loopback، وطُبقت عليها migrations المشروع فقط؛ لم تُضف إليها بيانات كتالوج ولم تُستخدم أي قاعدة بيانات حقيقية أو مشتركة.
- جرى فتح الموقع أيضًا عبر `127.0.0.1` لاختبار سماح Next.js بأصول التطوير ونجاح hydration.

## ملاحظات وحدود الاختبار

- بيانات المعاينة للعرض فقط؛ لم يُجرَ شراء أو تسليم أكواد، ولم تُضف سجلات إلى قاعدة بيانات المستخدم.
- في `npm test`، اختبارات PostgreSQL الستة التي تتطلب `TEST_DATABASE_URL` تتخطى التنفيذ عندما لا يكون هذا المتغير مضبوطًا. اختبار الكتالوج الوظيفي أعلاه استخدم قاعدة PGlite مؤقتة منفصلة ومُهيأة بالمخطط الفارغ.
- التحقق من الموبايل تم بمحاكاة Chromium عند 390×844؛ لا يتضمن أجهزة فعلية أو أنظمة تشغيل مختلفة.
